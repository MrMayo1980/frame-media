# Подключение Google-поиска и сервера

Теперь сценарий такой: **запрос → реальные сайты из Google → выбор сайтов → сбор медиа с найденных страниц → выбор файлов → скачивание**.

GitHub Pages уже размещает интерфейс. Чтобы он мог искать и читать страницы чужих сайтов, нужно один раз подключить сервер. Сервер подготовлен в папке `server`, а настройка Render — в `render.yaml`.

## 1. Создайте ключ поискового API

1. Откройте https://serpapi.com/ и создайте свой аккаунт.
2. Получите ключ на странице https://serpapi.com/manage-api-key .
3. Проверьте доступный лимит и условия тарифа перед использованием. Проект сам ничего не оплачивает и не подключает платный тариф.

Ключ нужен только серверу. **Не добавляйте его в GitHub, в код сайта или в поле пароля на сайте.**

Используется API `engine=google`, то есть настоящая органическая выдача Google, а не коллекции NASA/Commons и не сгенерированные результаты. Один запуск поиска делает один запрос SerpAPI; сбор с выбранных страниц не расходует дополнительные поисковые запросы.

## 2. Запустите подготовленный сервер

1. Откройте [готовую форму запуска Frame на Render](https://render.com/deploy?repo=https://github.com/MrMayo1980/frame-media) и войдите в свой аккаунт. Репозиторий и конфигурация будут выбраны автоматически.
2. Выберите **New → Blueprint**, подключите репозиторий https://github.com/MrMayo1980/frame-media . Render прочитает `render.yaml`.
3. Задайте две секретные переменные:
   - `SERPAPI_KEY` — ключ из первого шага.
   - `APP_ACCESS_KEY` — придуманный вами длинный случайный пароль для доступа к вашему серверу (рекомендуется не менее 24 символов). Это отдельный пароль, не ключ SerpAPI.
4. `ALLOWED_ORIGIN` уже задан: `https://mrmayo1980.github.io`.
5. Проверьте выбранный план и условия Render, затем запустите создание сервиса. В конфигурации указан free; если такой план недоступен в вашем аккаунте, не включайте платный без собственного решения.
6. Дождитесь успешного запуска и скопируйте HTTPS-адрес вида `https://frame-google-api-….onrender.com`.

Проверка: откройте `<адрес-сервера>/api/health`. Готовый сервер отвечает `{"ready":true,"service":"frame-google-api"}`. Эта проверка подтверждает наличие настроек, а корректность ключа поискового API проверяется первым реальным поиском.

У бесплатного сервиса возможен холодный запуск после простоя. Если первая проверка не ответила вовремя, дождитесь запуска в панели Render и повторите.

## 3. Подключите сайт

1. Откройте https://mrmayo1980.github.io/frame-media/ .
2. Нажмите **Подключение**.
3. Введите адрес сервера из Render и пароль `APP_ACCESS_KEY`.
4. Нажмите **Сохранить и проверить**.
5. Закройте окно. Введите запрос и нажмите **Найти сайты**.
6. Выберите сайты, типы и количество медиа, затем нажмите **Собрать медиа с выбранных сайтов**.

Адрес сохраняется в браузере. Пароль хранится в `sessionStorage` до закрытия вкладки; ключ SerpAPI остаётся только на Render. Не передавайте пароль посторонним: он разрешает расходовать ваш лимит поисковых запросов.

## Границы работы

- Сайты показываются в порядке релевантности Google. Google не сообщает точное число упоминаний фразы на всём сайте. Число «найденных страниц» относится только к страницам в текущей выдаче.
- Сбор читает до трёх найденных страниц каждого выбранного сайта, а не обходит весь сайт. Ссылка на исходную страницу сохраняется у каждого файла.
- Извлекаются обычные и ленивые изображения, `srcset`, изображения из метатегов и JSON-LD, прямые ссылки на GIF и видео. Встроенные YouTube-плееры, DRM, страницы за входом, JavaScript-галереи и защита от роботов не обходятся.
- Картинка на странице может быть оформлением страницы и не соответствовать запросу. Медиа с совпадениями в описании/адресе приоритизируются; окончательный выбор делаете вы.
- Файлы на CDN допустимы, если они указаны в HTML выбранной страницы. Сервер не переходит на другие сайты для сбора страниц.
- Ограничения: HTML до 2 МБ; файл до 150 МБ; ZIP до 300 МБ. HTTP-источники и локальные сетевые адреса не поддерживаются. Ошибки конкретных страниц отображаются отдельно.
- Скачать можно только публично доступные поддерживаемые медиа. Права использования проверяйте на исходной странице.

## Локальный сервер

Node.js 22+, `npm ci --prefix server`. Задайте переменные окружения из `.env.example`, затем `npm start --prefix server`. Пример содержит только имена и пустые значения; настоящие секреты не коммитьте.
