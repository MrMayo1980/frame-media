# Frame — поиск и скачивание медиа

Статический сайт на русском языке для GitHub Pages. Работает без сервера, ключей API и зависимостей времени выполнения.

## Что работает

- Реальный поиск в Wikimedia Commons (фото, видео, GIF) и NASA Images (фото и видео).
- Дополнительное подключение Openverse (фотографии с Flickr и других сайтов). По умолчанию выключено: анонимный доступ может быть ограничен источником, включая HTTP 401/403. Ошибки показываются отдельно и не мешают остальному поиску.
- Общий предел 12/24/48/100 результатов, с распределением между выбранными источниками.
- Список найденных сайтов и одновременная фильтрация по нескольким сайтам.
- Просмотр фотографий, GIF, видео; оригинальная страница, автор и лицензия.
- Коллекция из нескольких поисков; выбор показанных, снятие выбора, удаление отдельных файлов.
- ZIP с реальными файлами, `sources.json` и README со сведениями об ошибках.
- Все файлы в выбранную папку через File System Access API (поддерживаемые браузеры); иначе отдельные загрузки браузера.
- Прогресс, отмена, повтор неудачных загрузок, ссылки на оригиналы при ошибках.
- Адаптивная верстка, клавиатурное управление и системные диалоги.

## Локальный запуск

Нужны Python 3 и Node.js 22+ для проверок. Пакеты устанавливать не нужно.

```sh
npm start
# http://127.0.0.1:4188
npm test
```

## GitHub Pages

В репозитории включить Settings → Pages → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` проверяет приложение, собирает только публичные файлы и публикует при push в `main`. Все ссылки относительные: сайт работает в подпапке репозитория.

## Практические пределы

GitHub Pages размещает только статические файлы; сайт не является поисковым роботом всего интернета. Используются API выбранных медиатек. Для универсального веб-поиска и скачивания с сайтов, запрещающих CORS, потребуется отдельный сервер и поисковый API. Нельзя безопасно хранить секретные ключи в клиентском приложении.

Количество — верхний предел, не гарантия наличия столько результатов. Запросы к международным коллекциям лучше писать на английском. Источники могут выдавать ошибки или ограничивать частоту запросов; они явно отображаются. Превью и оригиналы зависят от доступности внешних сайтов. Видео NASA скачивается в MP4, предпочтительно компактный вариант из манифеста источника.

Один файл ограничен 150 МБ; ZIP — 300 МБ несжатых медиа, поскольку создаётся в памяти браузера. ZIP использует стандартный STORE: JPG/MP4 и другие уже сжатые форматы практически не выигрывают от повторного сжатия. Имена пронумерованы, Unicode сохраняется. ZIP32 проверяется независимым читателем Python `zipfile`.

При отдельных загрузках браузер может запросить разрешение на несколько скачиваний. Скачивание не обходит ограничения источников. Ошибки выводятся с исходными ссылками; успешные файлы доступны даже при частичных ошибках. При отмене ZIP не сохраняется, уже сохранённые отдельные файлы остаются.

Коллекция живёт до перезагрузки страницы и не отправляется на сервер. У файлов разные лицензии; сведения из API сохраняются в ZIP. Перед использованием проверяйте исходную страницу.
