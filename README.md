# Frame — Google → сайты → медиа

[Открыть интерфейс](https://mrmayo1980.github.io/frame-media/) · [Подключить сервер и Google-поиск](./SETUP.md)

[Запустить подготовленный сервер на Render](https://render.com/deploy?repo=https://github.com/MrMayo1980/frame-media)

## Сценарий

1. Ввести описание желаемого контента.
2. Получить сайты из органической выдачи Google с заголовками, описаниями и исходными ссылками.
3. Выбрать один или несколько сайтов.
4. Выбрать типы (фото, GIF, прямое видео) и количество, нажать «Собрать медиа».
5. Получить только медиа, найденные на выбранных страницах; отметить нужные и скачать отдельно или ZIP.

**Для реальной работы нужно подключение.** Интерфейс опубликован на GitHub Pages; сервер подготовлен для Render. Нужны ваш аккаунт Render и ключ SerpAPI. Ключи в репозиторий не включены. Без них интерфейс честно показывает необходимость подключения и не подставляет чужие медиатеки или демонстрационные результаты.

На первом шаге изображения не собираются. Сайты не зашиты заранее. Сортировка — релевантность Google, не выдуманное количество упоминаний. Сервер читает только найденные страницы выбранных сайтов, до трёх на сайт; страницы с защитой и контентом, доступным только через JavaScript, могут не поддерживаться.

## Устройство

- `index.html`, `style.css`, `app.js`, `web-client.js`: интерфейс GitHub Pages.
- `archive.js`: стандартный ZIP32 STORE в браузере, скачивание, контроль размеров.
- `server/`: Node.js API для Google через SerpAPI, извлечения медиа и скачивания через сервер.
- `render.yaml`: готовая конфигурация Render.
- `.github/workflows/pages.yml`: проверки и автоматическая публикация интерфейса.

Сервер проверяет пароль, подписывает результаты поиска и ссылки скачивания, запрещает локальные адреса и проверяет DNS/перенаправления при чтении внешних ресурсов. Ключ SerpAPI остаётся только на сервере. Извлечение не исполняет скрипты сторонних страниц. Файлы на CDN поддерживаются, если они указаны в выбранной странице. Ссылки на файлы действуют два часа, результаты для сбора — 30 минут.

## Проверки

```sh
npm test
npm ci --prefix server
npm test --prefix server
```

Статический интерфейс локально: `npm start`. API локально и полная настройка описаны в [SETUP.md](./SETUP.md). Проверки ZIP используют независимый читатель Python `zipfile`. Проверки сервера покрывают извлечение из HTML, группировку результатов Google, подписи, фильтрацию типов и блокировку локальных сетей. Проверки с тестовыми данными не считаются подтверждением живого поиска Google: его можно проверить после подключения вашего ключа и сервера.
