Ваша коллекция

Выбранные файлы сохраняются при новом поиске до закрытия страницы.

Скачивание

От поиска до вашей папки

  1. Введите запрос, выберите типы медиа, источники и количество результатов.
  2. После поиска отметьте нужные сайты. Выбор нескольких сайтов объединяет их результаты.
  3. Откройте просмотр или отметьте файлы галочками. Коллекцию можно собирать несколькими поисками.
  4. «Все файлы» сохраняет файлы в выбранную папку в поддерживаемом браузере. В остальных браузерах запускает отдельные загрузки — разрешите несколько скачиваний для сайта.
  5. «ZIP-архив» сохраняет одну загрузку с файлами и списком авторов, лицензий и ссылок.

GitHub Pages не запускает сервер. Сайт использует открытые API; отдельные источники могут ограничивать запросы и скачивание из браузера. Для таких файлов будет показана ошибка и ссылка на оригинал. ZIP ограничен 300 МБ, один файл — 150 МБ. Крупные файлы можно скачать на сайте источника.
